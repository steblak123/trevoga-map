## Встановлення — 2 хвилини

1. **Завантажте** [`trevoga-map-setup.exe`](https://github.com/steblak123/trevoga-map/releases/latest/download/trevoga-map-setup.exe) і запустіть.
   Якщо Windows покаже «Windows захистив ваш ПК», натисніть **Докладніше → Однаково запустити**. Так буває з усіма програмами без платного сертифіката підпису; код відкритий, його можна перевірити тут.
2. **Отримайте безкоштовний токен** для даних про тривоги: [форма на devs.alerts.in.ua](https://devs.alerts.in.ua/). Обов’язково дайте відповідь на лист, інакше токен не запрацює.
3. Під час першого запуску відкриються налаштування. **Вставте токен і позначте свої райони.** Готово.

Налаштування відкриваються подвійним кліком по карті, через ⚙ або з меню значка в треї.
Вони зберігаються в `%APPDATA%\trevoga-map\settings.json`.

## Оновлення

Віджет сам перевіряє нові версії на GitHub: за хвилину після запуску й далі кожні 6 годин.
Нову версію він завантажує у фоні й встановлює тихо, коли у ваших районах немає тривоги. Після цього віджет за кілька секунд повертається.
Усе це можна вимкнути в **Налаштування → Оновлення**. Там же є кнопки «Перевірити» й «Оновити зараз», а ще є пункт у меню трею.

## Часті питання

<details><summary><b>Це безпечно?</b></summary>

Код повністю відкритий. Віджет лише читає публічні дані про тривоги й цілі та нічого про вас не надсилає.
Ваш токен зберігається тільки на вашому комп’ютері.
</details>

<details><summary><b>Навіщо токен і чому його не вшито?</b></summary>

Дані про тривоги дає API alerts.in.ua за персональним токеном. Правила API забороняють передавати один токен багатьом людям, тому кожен отримує свій. Це безкоштовно.
</details>

<details><summary><b>Звідки відомо, де шахеди і які з них реактивні?</b></summary>

Положення цілей береться з відкритого API NEPTUN, який збирає повідомлення моніторингових каналів.
Реактивний шахед від звичайного віджет відрізняє так:
- за описом цілі від NEPTUN;
- за свіжими постами каналів про те саме місце;
- за швидкістю (звичайний летить до ~185 км/год).

У картці цілі видно, на чому ґрунтується висновок. Наведіть на ціль, і підказка покаже канали, які про неї писали: час і рядок із поста. У картці цілі ці канали можна клікнути.
</details>

<details><summary><b>Працює без інтернету?</b></summary>

Карта, райони й усі підкладки (супутник, дороги, міста) вбудовані в програму. Тривогам і цілям, звісно, потрібен інтернет.
</details>

<details><summary><b>Як видалити?</b></summary>

Параметри Windows → Програми → «Карта тривог» → Видалити. Автозапуск прибирається разом із програмою.
</details>

## Для розробників

Потрібен Node.js 20+.

```bash
npm install
npm start            # запуск віджета з вихідного коду
npm test             # тести читання постів каналів на тижні справжніх постів
npm run dist         # інсталятор dist/trevoga-map-setup.exe (локально)
```

Без інсталятора: `scripts\install.bat` встановить залежності, додасть автозапуск і запустить віджет.
Така git-копія теж оновлюється сама: віджет робить `git fetch` і, якщо у папці немає власних змін, підтягує нові коміти та перезапускається.

**Випуск нової версії.** Інсталятор збирає GitHub Actions ([`.github/workflows/release.yml`](.github/workflows/release.yml)), і всі встановлені віджети отримують його самі. Запустити збірку можна двома способами:
- тегом:
  ```bash
  git tag v1.2.0
  git push origin v1.2.0
  ```
- кнопкою на GitHub: **Actions → Release → Run workflow**.

Що нового береться з розділу `## 1.2.0` у [`CHANGELOG.md`](CHANGELOG.md).

**Без GitHub Actions** (наприклад, коли вони недоступні для акаунта) — зібрати на своєму Windows і викласти вручну:
1. `npm run release:local` — збирає `dist\trevoga-map-setup.exe`, `.blockmap` і `latest.yml` (вбудований токен перед збіркою видаляється).
2. GitHub → **Releases → Draft a new release**, тег `vX.Y.Z` (та сама версія, що в `package.json`), текст — з `CHANGELOG.md`,
   прикріпити ці три файли → **Publish release**. Автооновлення читає `latest.yml` з останнього релізу.

| Папка | Що там |
| --- | --- |
| `app/` | віджет, налаштування, плашки тривог, головний процес Electron |
| [`app/neptun/`](app/neptun/README.md) | шар цілей, вікно під картою, плитки, зум, підкладки карти |
| `app/update/` | автооновлення (GitHub Releases або git) |
| `build/` | збірка карти районів (`make-map.js`) і підкладок (`make-basemap.py`) |

Як усе влаштовано зсередини, описано в [`app/neptun/PROMPT.md`](app/neptun/PROMPT.md), план розвитку — у [`docs/PLAN.md`](docs/PLAN.md).

## Відмова від відповідальності

Віджет неофіційний і має лише інформаційний характер. Дані можуть надходити із затримкою.
**Не покладайтеся на нього як на єдине джерело оповіщення:** користуйтеся офіційними застосунками («Повітряна тривога», «Дія») та сиренами.
