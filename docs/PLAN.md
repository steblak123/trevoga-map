# План развития «Карты тривог»

Составлен по коду проекта на ноябрь 2026: Electron-виджет, тревоги alerts.in.ua, цели NEPTUN, панель нагрузки ПК,
подложки карты, автообновление.
Оценка: **быстро** — одна сессия; **средне** — 1–2 сессии; **долго** — несколько сессий или нужны внешние вещи.

## 1. Что стоит исправить

| Что | Почему | Реально? |

| Обновить Electron 33 до актуальной версии | 33-я давно без обновлений безопасности. ## 2. Что можно добавить: реально

Сначала самое полезное:

1. **«Мой дом» — точка вместо целого района.** Клик по карте (или по адресу) задаёт свою точку. Расстояние,
   «наближається», радиус и плашка считаются от неё, а не от границы района. На карте NEPTUN это главное.
   *Быстро.*
2. **Свои источники: ваши Telegram-группы.** Реально, два пути:
   - **бот в группе** — создать бота у @BotFather, добавить в группу (режим приватности выключить или дать админа);
     главный процесс читает новые сообщения через Bot API `getUpdates`. Просто, токен бота хранится локально;
   - **ваш аккаунт** (MTProto, библиотека `gramjs`, `api_id`/`api_hash` с my.telegram.org, один раз код входа) —
     читает любые каналы и группы, где вы есть, без бота.

   Дальше общий разбор: вид («шахед», «мопед», «реактивний», «ракета», «КАБ»), направление («на Біла Церква»,
   «курсом на захід»), место → координаты по справочнику населённых пунктов OCHA (≈30 тыс. с координатами, CC BY-IGO).
   На карте — своя отметка «з ваших каналів», низкая уверенность, живёт 20 минут, склеивается с целью NEPTUN рядом.
   *Средне, 1–2 сессии.* Риск: ложные срабатывания на фразах вроде «відбій по шахедах».
3. **Разный радиус по видам.** Ракеты и реактивные — 50 км, шахеды — 20, FPV — 5. *Быстро.*
4. **Сводка целей в трее.** Подсказка иконки («Біля вас 2 · БпЛА 11»), цвет иконки и список в меню. Полезно
   в режиме «Під ярликами», где по карте не покликать. *Быстро.*
5. **Тихие часы.** Ночью без звука, плашки по желанию. *Быстро.*
6. **«Ціль у вашій області».** Для сообщений, где названа только область, если это ваша область. *Быстро.*
7. **Журнал «было рядом» за сутки.** Что подлетало к вашим районам и когда, в окошке или отдельном окне.
   *Средне.*
8. ~~**Обновление в один клик.**~~ Сделано: автообновление из GitHub Releases для установщика и через git для
   git-копии (`app/update/`), пункт в трее и раздел «Оновлення».
9. **Уведомления Windows** (центр уведомлений) как вариант к своей плашке. *Быстро.*
10. **Резерв для тревог.** Если alerts.in.ua недоступен или токена нет, брать тревоги из NEPTUN
    (`/api/v1/alerts`, районы по названию). *Средне.*
11. **Горячая клавиша** — показать или спрятать виджет, сразу приблизить к своим районам. *Быстро.*
12. **Звук по видам.** Для ракет и баллистики — свой, заметнее; для дронов — тихий. *Быстро.*

## 3. Можно, но выигрыш небольшой

- Светлая тема или компактный режим виджета.
- Лента сообщений из Telegram-каналов (`/api/v1/messages` NEPTUN) под картой. Много текста, а вы просили
  без лишнего.
- Версия для macOS или Linux: `app/native.js` (рабочий стол, нагрузка ПК) написан под Windows. Долго.

## 4. Нереально или не стоит делать

| Что | Почему нет |
| --- | --- |
| Точные позиции дронов «как радар» | Данные — из сообщений в Telegram через NEPTUN. Задержка в минуты и погрешность в километры заложены в сам источник |
| Предсказать, куда упадёт или ударит цель | Таких данных нет, а ошибка может стоить жизни |
| Сбития, пуски, аэродромы, как в легенде NEPTUN | Их нет в открытом API, только в закрытом `/api/v1/live`. Взрывы теперь берём из постов каналов (`intel.booms`) |
| Подложка карты NEPTUN под нашими отметками | Их тайлы и стиль — не часть открытого API. Встроить можно только карту целиком (`/embed/map`) — вместе с их отметками. Свою похожую сделали из тех же открытых данных: «Темний супутник» |
| Заменить официальные сигналы тревоги | Виджет информационный. Сирены, «Повітряна тривога» и «Дія» важнее |
| Пуш-уведомления на телефон из этого виджета | Нужен свой сервер и мобильное приложение; это уже другой проект |
| Сделать «один в один как NEPTUN» (их вид, логотип, тексты) | Их бренд и дизайн принадлежат им. Свой спокойный стиль — да, копию — нет |
| Цели в режиме «Під ярликами» с кликами | Windows не отдаёт мышь окну под ярлыками. Обход — трей и горячие клавиши (пункты 4 и 11) |
| Дома на подложке, как в Google Maps | Миллионы контуров зданий — гигабайты; при наибольшем зуме виджета 1 пиксель ≈ 150–200 м, дом там не виден. Есть дороги, застройка и названия, при желании — зум сильнее только для своих районов |
| Свежий спутник каждый день | Ежедневные снимки (Sentinel Hub) платные и закрыты облаками; взят безоблачный годовой Sentinel-2 cloudless |
