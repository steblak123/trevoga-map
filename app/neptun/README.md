# Цілі на карті (NEPTUN)

Шар для віджета «Карта тривог»: БпЛА, ракети, балістика, КАБ, авіація та розвідники на карті в реальному часі,
панель цілей і картка цілі. Дані — відкритий API [NEPTUN](https://neptun.in.ua/developers), токен не потрібен.
Тривоги, як і раніше, беруться з alerts.in.ua.

- **Мітки на карті**: іконка за типом цілі, покажчик курсу, «×3» для групи. Між оновленнями мітка рухається
  за курсом і швидкістю від останньої згадки, у межах лімітів для кожного типу.
- **Панель цілей** (ліворуч угорі): лічильники за типами, «по області» (повідомлення без точки),
  час даних і стан зв’язку, найближча ціль до ваших районів. Клік по лічильнику показує цілі цього типу по черзі.
- **Картка цілі** (клік по мітці): курс, швидкість, час останньої згадки, відстань до ваших районів,
  кількість джерел і достовірність, точність; для вибраної цілі на карті видно трек, лінію курсу й зону похибки.
- Повідомлення, де названо лише область (`areaOnly`), точкою на карті не малюються. Спостереження без тривоги
  (`advisory`, наприклад зліт МіГ-31К) показуються приглушено.

## Встановлення у свою копію

1. Скопіюйте цю папку в `app/neptun/`.
2. `app/widget.html`: дозвольте з’єднання з NEPTUN у `Content-Security-Policy` і підключіть шар після `widget.js`:

   ```html
   <meta http-equiv="Content-Security-Policy" content="default-src 'self'; style-src 'self' 'unsafe-inline'; connect-src 'self' https://neptun.in.ua wss://neptun.in.ua">
   ```

   ```html
   <script src="widget.js"></script>
   <script src="neptun/index.js"></script>
   ```

3. `app/settings.html`: після `settings.js` додайте

   ```html
   <script src="neptun/settings.js"></script>
   ```

4. `app/main.js`: після рядка `const native = require('./native');` додайте

   ```js
   require('./neptun/main'); // NEPTUN targets layer: opens its links in the browser
   ```

Якщо ваша копія збігається з репозиторієм, можна замість кроків 2–4 просто замінити ці три файли.
`app/assets/map.json` міняти не обов’язково: параметри проєкції для поточної карти вшиті в `widget.js`.

## Налаштування

У вікні налаштувань з’являється розділ «Цілі на карті · NEPTUN». Значення зберігаються в
`%APPDATA%\trevoga-map\settings.json`:

```json
"neptun": { "markers": true, "panel": true }
```

- `markers` — показувати цілі. Якщо вимкнено, з’єднання з NEPTUN закривається.
- `panel` — лічильники й найближча ціль. Рядок «станом на … · NEPTUN» лишається завжди, поки цілі показуються:
  цього вимагають умови API.

## Файли

| Файл | Що робить |
| --- | --- |
| `index.js` | Підключає стилі та скрипти шару до `widget.html` |
| `client.js` | WebSocket `wss://neptun.in.ua/api/v1/stream`: перепідключення з паузами до 30 с, сторожовий таймер, резервний REST `GET /api/v1/threats` не частіше ніж раз на 15 с |
| `types.js` | Типи цілей: назви, кольори, іконки, прогноз руху між оновленнями |
| `geo.js` | Проєкція Ламберта (як у `build/make-map.js`), відстані, напрямки, геометрія районів |
| `widget.js`, `widget.css` | Мітки, панель, картка, підказки |
| `settings.js` | Розділ у вікні налаштувань |
| `main.js` | Головний процес: посилання з вікон застосунку відкриваються в браузері |

## Умови NEPTUN

- Поруч із даними має бути видиме посилання на NEPTUN. Воно є в панелі й у картці, відкривається в браузері.
- REST не частіше ніж раз на 5 с. Шар працює через WebSocket, REST — лише резерв при обриві.
- NEPTUN — агрегатор повідомлень, а не офіційна система оповіщення: позиції приблизні й можуть запізнюватися.
- Повні умови: <https://neptun.in.ua/api-terms>.
