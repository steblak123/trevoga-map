# Цілі на карті

Шар для віджета «Карта тривог»: шахеди, ракети, балістика, КАБ, авіація та розвідники на карті в реальному часі,
список цілей біля ваших районів, лічильники під картою, картка цілі, коротка плашка, коли ціль підлітає, і
підкладки карти без інтернету (супутник, дороги, міста). Дані про цілі — відкритий API
[NEPTUN](https://neptun.in.ua/developers), токен не потрібен. Детально, що і як влаштовано, — у [`PROMPT.md`](PROMPT.md).

- **Мітки на карті**: іконка за типом (шахед, **реактивний шахед**, FPV, розвідник, ракета, балістика, КАБ, МіГ-31К),
  покажчик курсу, «×2» для групи з повідомлення. Між оновленнями мітка рухається за курсом і швидкістю.
- **Реактивний чи звичайний.** Відкритий API NEPTUN дає обом тип `uav` (точна позначка `subtype: "jet"` є лише в
  закритому API), тому по черзі: `subtype`, якщо прийде; слово «реактивний» у назві чи описі цілі; свіжі пости каналів
  про це ж місце (`GET /api/v1/messages`, `intel.js`); виміряна швидкість від 300 км/год. У картці цілі в рядку «Тип»
  видно, звідки висновок («@monitor1654 11:58», «опис», «420 км/год», «ймовірно»).
- **Джерела при наведенні.** Підказка над ціллю показує, хто про неї писав: до трьох каналів із часом і рядком
  поста (спершу ті, що назвали саме цей вид цілі), і скільки підтверджень налічив NEPTUN. Якщо пост не знайшовся —
  «NEPTUN · зведення моніторингових каналів». У картці цілі канали — кнопки, клік відкриває канал у Telegram.
- **Траєкторії**: звідки ціль летіла (лінія від першої згадки) і куди летить (напівпрозорий сектор ±12°, ±22° —
  якщо курс оцінковий).
- **Звідки летить**: у картці цілі рядок «Звідки» (напрям і район або «з моря», «з-за кордону») — з першої згадки
  треку, а якщо її немає, оцінка назад за курсом (лінія пунктиром, «оцінка»). Для обраної цілі й цілей біля ваших
  районів лінія «звідки» на карті є завжди.
- **Шахеди без курсу** на карті не малюються, якщо вони не ближче 50 км до ваших районів, — вони є в плитках
  («N без курсу»), клік по плитці показує їх по черзі. Так само робить і карта NEPTUN. Розвідники, які зазвичай
  кружляють без курсу, видно завжди.
- **Одна мітка «×N»** для цілей, що на екрані накладаються і летять в один бік. Різні напрямки не зливаються: мітки
  розходяться віялом з тонкою лінією до справжнього місця. Клік по «×N» — список у вікні під картою.
- **Цілі за межами карти** притиснуті до краю, стрілка — куди саме. Над морем без назви місця — «над Чорним морем ·
  у бік Одеської області».
- **Пунктирний контур області** для повідомлень, де названо лише область.
- **Нічого не пишеться поверх карти.** Під картою, поруч із плитками навантаження ПК:
  - **вікно** (ліворуч або праворуч): цілі біля ваших районів з відстанню, «наближається», скільки часу поруч;
    якщо поруч нікого — найближча; клік по цілі на карті показує тут же її курс, швидкість, час, джерела, точність;
  - **плитки з графіком за 30 хв**, як у ЦП і пам’яті: «Усього цілей · N без курсу», окремо за типами
    (Реактивні, БпЛА, FPV, Ракети…), «Біля вас (20 км)». Клік — цілі по черзі, наведення — список.
- **Зум**: кнопки «+», «−», «◎» (мої райони), «⤢» (уся карта) праворуч угорі, колесо миші над картою; коли карта
  наближена, її можна тягнути мишею (у звичайному масштабі перетягування, як і раніше, рухає віджет).
- **Підкладки карти** (`basemap.js`, папка `basemap/`), без інтернету:
  - «Карта з дорогами» — дороги, залізниці, річки, водосховища, забудова, назви міст і містечок;
  - «Супутник» — знімок Sentinel-2: уся карта одним малим файлом, ближче вантажаться плитки 512 px лише видимої
    частини; райони стають напівпрозорими, тривоги лишаються червоними;
  - «Супутник і дороги».

  Дрібніші дороги й містечка з’являються при наближенні, назви не налазять одна на одну, на назви областей і
  на мітки цілей. Шари зібрано скриптом [`build/make-basemap.py`](../../build/make-basemap.py), джерела й ліцензії —
  у [`basemap/LICENSE.md`](basemap/LICENSE.md).
- **Посилання на джерела** — дрібно в лівому верхньому куті карти: alerts.in.ua, NEPTUN (коли цілі ввімкнено) та
  джерела ввімкненої підкладки. Цього вимагають умови обох API та ліцензії карт.
- **Плашка** «Ціль біля ваших районів» — лише коли нова ціль входить у радіус 5 / 10 / 20 / 50 км: на 2 секунди,
  напівпрозора, кліки проходять крізь неї. Без звуку за замовчуванням.
- **FPV можна приховати** — з карти, вікна, плиток і плашок.

Плашки тривоги й відбою віджета (`app/overlay.html`) так само показуються 2 секунди, напівпрозорі й не заважають
клікам.

## Встановлення у свою копію

1. Скопіюйте цю папку в `app/neptun/`.
2. `app/widget.html` — дозвольте з’єднання в `Content-Security-Policy` і підключіть шар після `widget.js`:

   ```html
   <meta http-equiv="Content-Security-Policy" content="default-src 'self'; style-src 'self' 'unsafe-inline'; connect-src 'self' https://neptun.in.ua wss://neptun.in.ua">
   ```

   ```html
   <script src="widget.js"></script>
   <script src="neptun/index.js"></script>
   ```

3. `app/settings.html` — після `settings.js`:

   ```html
   <script src="neptun/settings.js"></script>
   ```

4. `app/main.js` — після рядка `const sysmon = require('./sysmon');`:

   ```js
   require('./neptun/main'); // NEPTUN targets layer: opens its links in the browser
   ```

5. `app/preload.js` — останнім пунктом у `contextBridge.exposeInMainWorld('bridge', { … })`:

   ```js
   // NEPTUN targets layer (app/neptun): its own IPC channels, all prefixed "neptun:".
   neptun: {
     send: (channel, data) => ipcRenderer.send('neptun:' + channel, data),
     on: (channel, cb) => ipcRenderer.on('neptun:' + channel, (_e, data) => cb(data)),
   },
   ```

   Без цього кроку все працює, крім плашки.

`app/assets/map.json` міняти не обов’язково: параметри проєкції поточної карти вшиті в `widget.js`.

## Налаштування

Розділи «Карта» і «Цілі на карті» у вікні налаштувань. Значення — у `%APPDATA%\trevoga-map\settings.json`:

```json
"neptun": { "markers": true, "panel": true, "hideFpv": false, "alert": true, "alertKm": 20, "alertSound": false, "cardSide": "left", "basemap": "none" }
```

| Ключ | Що означає |
| --- | --- |
| `markers` | Показувати цілі. Вимкнено — з’єднання закривається, усе інше ховається |
| `panel` | Плитки з кількістю цілей під картою |
| `hideFpv` | Приховати FPV-дрони скрізь |
| `alert` | Плашка, коли нова ціль входить у радіус |
| `alertKm` | Радіус: 5, 10, 20 або 50 км (і для списку, і для плашки) |
| `alertSound` | Короткий подвійний сигнал разом із плашкою; гучність — з розділу «Сповіщення» |
| `cardSide` | Вікно під картою: `left` або `right` (на широкому віджеті) |
| `basemap` | Підкладка: `none`, `map` (дороги), `sat` (супутник), `hybrid` (супутник і дороги); працює й з вимкненими цілями |

## Файли

| Файл | Що робить |
| --- | --- |
| `index.js` | Підключає стилі та скрипти шару до `widget.html` |
| `client.js` | WebSocket `wss://neptun.in.ua/api/v1/stream`: перепідключення з паузами до 30 с, сторожовий таймер, резервний REST `GET /api/v1/threats` не частіше ніж раз на 15 с |
| `types.js` | Типи цілей: назви, кольори, іконки, реактивний чи звичайний (`classify`), прогноз руху між оновленнями |
| `intel.js` | Пости каналів (`GET /api/v1/messages`, раз на 30 с): який шахед згадано як реактивний |
| `geo.js` | Проєкція Ламберта (як у `build/make-map.js`), відстані, напрямки, геометрія районів |
| `zoom.js` | Зум карти: кнопки, колесо, перетягування наближеної карти |
| `basemap.js`, `basemap/` | Підкладки карти: супутник (`sat/`, `sat.js`), дороги й міста (`vector.js`), джерела (`LICENSE.md`) |
| `hud.css`, `fonts/` | Стиль HUD-вікон і плашок; шрифти Tektur і Fira Sans Condensed (SIL OFL) |
| `widget.js`, `widget.css` | Мітки, траєкторії, групи, стрілки біля краю, контури областей, вікно й плитки під картою, підказки |
| `alert.html`, `alert.js` | Плашка «Ціль біля ваших районів» на 2 секунди |
| `settings.js` | Розділ у вікні налаштувань, кнопка «Перевірити» |
| `main.js` | Головний процес: вікно плашки, канали `neptun:*`, посилання відкриваються в браузері |
| `PROMPT.md` | Повний опис: що, як і звідки |
