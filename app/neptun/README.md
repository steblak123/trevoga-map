# Цілі на карті

Шар для віджета «Карта тривог»: шахеди, ракети, балістика, КАБ, авіація та розвідники на карті в реальному часі,
список цілей біля ваших районів, лічильники під картою, картка цілі, коротка плашка, коли ціль підлітає, і
підкладки карти без інтернету (супутник, дороги, міста). Дані про цілі — відкритий API
[NEPTUN](https://neptun.in.ua/developers), токен не потрібен. Детально, що і як влаштовано, — у [`PROMPT.md`](PROMPT.md).

- **Мітки на карті**: іконка за типом (шахед, **реактивний шахед**, FPV, розвідник, ракета, балістика, КАБ, МіГ-31К),
  покажчик курсу, «×2» для групи з повідомлення. Між оновленнями мітка рухається за курсом і швидкістю.
- **Реактивний чи звичайний.** Відкритий API NEPTUN дає обом тип `uav` (точна позначка `subtype: "jet"` є лише в
  закритому API), тому по черзі: `subtype`, якщо прийде; слово «реактивний» у назві чи описі цілі; пости каналів про це
  ж місце (`GET /api/v1/messages`, `intel.js`) — реактивним шахед стає, лише коли так пишуть Повітряні Сили або щонайменше
  два різні канали; якщо один — лишається звичайним, як на карті NEPTUN, з позначкою «можливо реактивний · канал»;
  виміряна швидкість від 300 км/год. У картці цілі в рядку «Тип» видно, звідки висновок.
- **Джерела при наведенні.** Підказка над ціллю показує, хто про неї писав: до трьох каналів із часом і рядком
  поста (спершу ті, що назвали саме цей вид цілі), і скільки підтверджень налічив NEPTUN. Якщо пост не знайшовся —
  «NEPTUN · зведення моніторингових каналів». У картці цілі канали — кнопки, клік відкриває канал у Telegram.
- **Траєкторії**: звідки ціль летіла (лінія від першої згадки) і куди летить (напівпрозорий сектор ±12°, ±22° —
  якщо курс оцінковий).
- **Звідки летить**: у картці цілі рядок «Звідки» (напрям і район або «з моря», «з-за кордону») — з першої згадки
  треку, а якщо її немає, оцінка назад за курсом (лінія пунктиром, «оцінка»).
- **Траєкторії лише для вибраної цілі.** Звідки летить і промінь «куди» малюються тільки для цілі, на яку ви
  клікнули або навели мишу (або для групи); на решті — маленька стрілка курсу. Так карта не світиться.
- **Приціл.** Ракета чи КАБ, про які відомо лише, куди летять («Ракета курсом на Балаклія»: курсу в даних немає),
  стоять на цьому місці в пунктирному прицілі.
- **Клік по рядку стрічки** наближає карту до вибуху або вибирає ціль.
- **Шахеди без курсу** далі ніж 50 км від ваших районів — бліді: про них відомо лише місце, біля якого їх бачили.
- **Ціль «у районі».** Коли повідомлення називає район, а не місце («дрон Кропивницький район»), NEPTUN ставить точку в
  центр міста, за яким названо район. Таку ціль видно блідою, сам район обведено тонким пунктиром, місце підписано
  «Кропивницький р-н», у плашці відстань «≈». Так само, коли NEPTUN сам каже, що точка груба (±30 км і більше): навколо
  неї пунктирне коло похибки.
- **Маршрути з ваших каналів** (`routes.js`). Кожен пост читається рядок за рядком: яка ціль, скільки, де вона, куди
  й звідки летить. Відповідь у Telegram продовжує ціль поста, на який відповідає (Telegram дає й цитату), тож
  «→Нова Прага» після «Реактивний на Новий Стародуб» — та сама реактивна ціль; «Другий за ним йде, Інгулецьке» — друга.
  Пост без відповіді («→Сасівка») продовжує найближчу ціль каналу, яка могла туди долетіти; «Ще 1 …» і списки
  «1 → Компаніївка / 1 → Долинська» — нові цілі, якщо жодна з наявних не могла туди долетіти; інакше рядки списку
  розподіляються між цілями каналу всі разом: якнайбільше пар, і з них набір з найменшою сумою «відстань × відхилення
  від курсу цілі + хвилини мовчання про неї + інший рід / інша кількість». Допис, відредагований у Telegram (той самий
  номер, інший текст), читається заново разом з усіма дописами каналу за останню годину. Назви шукаються в довіднику (`basemap/places.js`): з однойменних сіл
  — найближче до цілі або до місць, про які канал зазвичай пише; місто важить більше за село («П'ятихатки» — місто).
  Розуміє скорочення каналів (Кроп, Знам, Долік, Мико, «Знамʼянка 2га», «с.Нове», «Байраки»), заголовки
  «✈️Кіровоградщина:» загальноукраїнських каналів, «(2х)», «—» / «Не спостерігається» (ціль зникла), «чисто».
  Ціль NEPTUN бере пости ваших каналів про цілі за 15 км від неї (25 км — коли відомо лише, куди летить), навіть якщо
  місце назване інакше; у картці — рядок маршруту «@канал · … → Високі Байраки → Кандаурове»; шахед без курсу бере курс
  із маршруту. Один і той самий пост зі стрічки NEPTUN і з Telegram рахується один раз.
  Відповідь, що ціль повернула («Відвернув на Варварівку/Братське»), міняє її курс; курс із каналу береться й замість
  курсу NEPTUN, якщо пост новіший за оновлення треку (у картці — «за каналом»).
  **«Зник» і «Збили»**: «Зник», «Не спостерігається», «не фікс», «—» — ціль «втрачена»: лишається 5 хв на останньому
  місці, бліда, повільно блимає (може йти низько); нова точка в каналі повертає її. «Збили», «Мінус», «Впав»,
  «Недолетів» і «Вилетів з області» — одразу знімають ціль каналу, а ціль NEPTUN поруч (15 км) стає сірою з позначкою
  «Збито» / «Вилетів» і не дає плашки, поки NEPTUN не оновить її.
  **Ціль без курсу** бере курс із того, як вона зсувалася між оновленнями NEPTUN (і з її `trail`), за останні 30 хв,
  якщо зсув від 3 км і швидкість можлива (у картці — «оцінка за рухом»). Якщо зсуву немає, у вибраної цілі —
  пунктирне коло, де вона може бути зараз: типова швидкість × час без даних (до 60 км), з підписом «N хв без даних».
  **Рух без швидкості**: у відкритому API швидкість майже ніколи не приходить. Ціль із курсом (свого NEPTUN, з каналу
  або оцінкою за рухом) рухається між оновленнями зі звичайною швидкістю свого типу (шахед 150 км/год, реактивний 450,
  розвідник 120, FPV 60, ракета 750, КАБ 400) у тих самих межах, що й на карті NEPTUN; у картці — «За курсом +N км
  (оцінка)», ETA рахується так само. «Курсом на Х» (`destination`) стоїть на Х у прицілі: це місце, куди вона летить.
  **Курс ракет і КАБ** «курсом на Х» без курсу: з того, як ціль зсувалася; зі слів постів про неї («Ракета з
  Харківщини курсом на Полтаву», «КАБ від Вовчанська» — `intel.courseFromText`); КАБ — від найближчої точки лінії
  фронту й кордону (летить до ~90 км), оцінка. У картці біля курсу — звідки він: «за каналом», «оцінка за рухом»,
  «за повідомленням», «оцінка: від фронту».
  **Кілька каналів про одну ціль**: цілі лише з каналів, шляхи яких за останні хвилини сходяться (20 км, 6 хв), —
  одна мітка з усіма каналами; місце — найсвіжіша справжня точка («Бокове»), курс — туди, куди пише інший канал
  («→Братолюбівка»).
  **Куди й звідки на карті**: для вибраної цілі й цілей у подвійному радіусі — назва місця, куди летить («→ Аджамка»,
  жирно, з крапкою й пунктиром від цілі), і звідки (тихіше), у називному відмінку зі довідника; назви підкладки
  відступають. Ціль без курсу біля вас — тихе коло, куди могла долетіти; курс-оцінка — ширший сектор (±40°).
  **Без стрибків**: мітка між оновленнями лише повзе (чверть звичайної швидкості, до 4 км; з відомою швидкістю — до
  8 км), а куди може долетіти за 10 хв — м'який сектор попереду (±20°, оцінений курс ±34°), для вибраної цілі й цілей
  біля вас. Курс з каналу — по відрізку від 8 км (`STEADY_KM`), слід — рівні відрізки між поворотами (Дуглас — Пекер,
  2,5 км), для цілей з каналу — по селах з постів.
  **Куди летить**: «на Павлиш», «курс Павлиш» — ціль дивиться на Павлиш (і замість курсу NEPTUN, якщо пост новіший); до
  нього — широка напівпрозора смуга, там — коло «куди може влучити» (3 км + 0,8 км/хв від поста, до 15 км), що повільно
  «дихає»; назви «куди» й «звідки» — жирні.
  **Збито / втрачено**: «Мінус», «Збили» — маленький червоний хрестик біля мітки, без секторів і кіл, 4 хв, потім мітка
  зникає (і ціль NEPTUN поруч теж); «Зник», «Пропав», «—» — пунктирний хрестик і коло «без даних N хв ≈ M км».
  **Як на карті NEPTUN** (правила з легенди їхньої карти: «Дрони без курсу на карті не малюємо, хіба що вони
  поруч із Домом»): шахеди й розвідники без курсу (свого в NEPTUN або з маршруту вашого каналу) не малюються, крім
  тих, що за 50 км від вас (або у вашому радіусі), а й тих — коли за 20 км є дрон із курсом (стільки ж або більше):
  це той самий. Вони є в лічильниках («N без курсу»). Курс-здогадка (зі слів «з Кіровоградщини», від фронту для КАБ)
  не рахується курсом: тьмяна стрілка, без «наближається / віддаляється», мітка не зсувається, сектора немає.
  **Одна ціль — кілька міток** (`fuse.js`): NEPTUN ставить мітку на кожне місце з поста — «курсом на X» стоїть
  в X, а не там, де ціль, і живе ~8 хв після свого одного поста, тож реактивний, про якого писали «на Долину /
  Хоростків», «на Хоростків», «на Копичинці», «на Чортків», стояв чотири рази. Мітки однієї цілі знаходяться так:
  1) за словами постів — рядок, де назви двох міток з’єднані як маршрут («Яблуневе на Мрин», «від Біленьке в бік
  Василівки», «Путивль > Дубов’язівка») або як варіанти («Мрин / Носівку», «Борзна/Ічня»), — про одну ціль; перелік
  («Біленьке, Комишуваха»), окремі речення, групи («2х», «ці 2 реактивні») — ні; 2) за послідовністю одного каналу —
  канал, що веде одну ціль («реактивний далі на Седнів», за хвилину «далі на Вересоч», «далі на Ядути»): пости про
  одну ціль (без «інший», «ще 1», переліку), один за одним у межах 5 хв, без постів про інші цілі між ними, і місця
  не далі, ніж рід цілі долетить; 3) за польотом, коли жоден пост не з’єднує їх: нова мітка з’явилась за 15 с – 6 хв після того, як стару перестали оновлювати, і лежить не далі, ніж
  рід цілі долетить за цей час; лише коли це ясно — пара найближча для обох, наступний кандидат помітно гірший,
  курс (якщо є в обох) не розвертається. Над Запоріжжям три реактивні, що ходять колами, одне одного не заміняють; мітки, які один пост зробив або оновив разом далеко одна від одної (рядки переліку), — дві цілі, жоден ланцюжок їх не з’єднує;
  один реактивний, про якого написано «Хоростків», потім «Копичинці», потім «Чортків», — одна ціль. Рішення за
  польотом не скасовуються, коли новіша мітка оновлюється (стара не повертається); скасовуються, коли стару
  оновили вже після появи нової. Лишається найновіша (з варіантів «Мрин / Носівку» — ближча до вас); решта не
  малюються й не рахуються, її шлях видно в підказці («Долина → Хоростків →») і на карті у вибраної (пунктир через
  них), для варіантів — пунктир до «або Носівка». Номер, джерела («Джерела» — з усіх міток) і рід («реактивний», якщо
  так писали про будь-яке з місць) переходять до найновішої; курс, якщо в неї немає свого, — з попереднього місця.
  «Шахед», якого ніхто не назвав шахедом, у тому ж місці, де ракета, — ця ракета («бандероль» — ракета).
  **Зведення каналу** без відповіді («1 → Компаніївка ⏎ 1 → Долинська») — це де зараз цілі, які канал веде: рядки
  розходяться по них разом, найближчі пари першими; нова ціль — лише коли рядок каже («Ще 1», «новий», «за ним»)
  або жодна ціль туди не долетіла б. Тип — лише з рядка-заголовка («По реактивам»), не з сусіднього рядка. Назви нової
  цілі — біля місця, про яке місцевий канал писав останнім (10 хв), або біля вас; загальноукраїнський канал (його
  місця розкидані далі ніж на 120 км від середини) — біля своєї середини.
  **Зони** навколо вашої точки — два кола (дрони, ракети) з підписом відстані; зона з ціллю стає помаранчевою / червоною.
  Відстань рахується від точки («Поблизу вашої точки», «над вами»), без неї — до меж ваших районів.
  **Цілі лише з каналу**: остання точка маршруту вашого каналу, біля якої (25 км) NEPTUN не має цілі того ж роду,
  малюється з пунктирним кільцем, рахується в «Біля вас» і плашці (з назвою каналу); зникає, коли NEPTUN її має або
  канал мовчить про неї 7 хв (реактивні), 4 хв (ракети), 3 хв (КАБ), 8 хв (решта); після цього ще 4 / 3 / 2 / 6 хв стоїть
  бліда («Застарілі дані»), щоб не блимала між дописами. Локальний канал малюється, навіть якщо його читає й сам NEPTUN
  (@krop_vanek): NEPTUN робить ціль не з кожного допису; всеукраїнські зведення зі стрічки NEPTUN — ні. Вимикається в налаштуваннях.
  **Швидше, коли поруч**: поки ціль у радіусі або у ваших районах тривога, `main.js` читає канали кожні 8 с (інакше 45 с;
  канал, що відповів помилкою чи 429, відпочиває хвилину), `intel.js` — пости NEPTUN кожні 10 с (інакше 30 с).
  Тести на тижні справжніх постів @krop_vanek, @shpk_krop, @povitryanatrivogaaa: `npm test` (`tests/routes.test.js`).
- **Вибухи** з постів каналів (`intel.js`): рядок зі словами «вибух», «приліт», «влучання» (але не «можливі вибухи», «не
  чути») і назвою міста, знайденою в довіднику населених пунктів (`basemap/places.js`), — значок на 40 хвилин; наведення
  показує канали, час і рядок поста.
- **Стрічка подій** під картою (`ticker.js`): тривоги й відбої (області, або райони, якщо не вся область), нові цілі,
  вибухи — «час · подія · район, область — джерело»; біжить, при наведенні зупиняється.
- **Одна мітка «×N»** для цілей, що на екрані накладаються і летять в один бік. Різні напрямки не зливаються: мітки
  розходяться віялом з тонкою лінією до справжнього місця. Клік по «×N» — список у вікні під картою.
- **Цілі за межами карти** притиснуті до краю, стрілка — куди саме. Над морем без назви місця — «над Чорним морем ·
  у бік Одеської області».
- **Пунктирний контур області** для повідомлень, де названо лише область.
- **Нічого не пишеться поверх карти.** Під картою, поруч із плитками навантаження ПК:
  - **вікно** (ліворуч або праворуч): цілі біля ваших районів з відстанню, «наближається», скільки часу поруч;
    якщо поруч нікого — найближча; клік по цілі на карті показує тут же її курс, швидкість, час, джерела, точність;
  - **плитки з графіком за 30 хв**, як у ЦП і пам’яті: «Усього цілей · N без курсу», окремо за типами
    (Реактивні, БпЛА, FPV, Ракети…), «Біля вас (20 км)». Клік — цілі по черзі, наведення — список.
- **Зум**: кнопки «+», «−», «◎» (мої райони), «⤢» (уся карта) праворуч угорі, колесо миші над картою; коли карта
  наближена, її можна тягнути мишею (у звичайному масштабі перетягування, як і раніше, рухає віджет).
- **Підкладки карти** (`basemap.js`, папка `basemap/`), без інтернету:
  - «Карта з дорогами» — дороги (до третьорядних при сильному наближенні), залізниці, річки, водосховища, забудова;
  - «Супутник» — знімок Sentinel-2: уся карта одним малим файлом, ближче вантажаться плитки 512 px лише видимої
    частини; ще ближче, коли є інтернет, — плитки EOX прямо з сервера (браузер тримає їх у кеші тиждень);
  - «Супутник і дороги» та «Темний супутник» (притемнений знімок, тонкі блакитні дороги, тривоги — легка заливка з контуром).

  Назви — в усіх режимах: райони з ~1,8× (ваші — блакитні), міста за величиною, села з 13×; не налазять одна на одну, на
  назви областей і на мітки цілей. Зум — до 100×. Шари зібрано скриптом
  [`build/make-basemap.py`](../../build/make-basemap.py), джерела й ліцензії — у [`basemap/LICENSE.md`](basemap/LICENSE.md).
- **Посилання на джерела** — дрібно в лівому верхньому куті карти: alerts.in.ua, NEPTUN (коли цілі ввімкнено) та
  джерела ввімкненої підкладки. Цього вимагають умови обох API та ліцензії карт.
- **Плашка** «Ціль біля ваших районів» — лише коли нова ціль входить у радіус 5 / 10 / 20 / 50 км: на 5 секунд (у режимі «Акуратний» — без підсвітки),
  напівпрозора, кліки проходять крізь неї. Без звуку за замовчуванням.
- **FPV можна приховати** — з карти, вікна, плиток і плашок.

Плашки тривоги й відбою віджета (`app/overlay.html`) так само показуються 5 секунд, напівпрозорі й не заважають
клікам.

## Встановлення у свою копію

1. Скопіюйте цю папку в `app/neptun/`.
2. `app/widget.html` — дозвольте з’єднання в `Content-Security-Policy` і підключіть шар після `widget.js`:

   ```html
   <meta http-equiv="Content-Security-Policy" content="default-src 'self'; style-src 'self' 'unsafe-inline'; connect-src 'self' https://neptun.in.ua wss://neptun.in.ua">
   ```

   ```html
   <script src="widget.js"></script>
   <script src="neptun/index.js"></script>
   ```

3. `app/settings.html` — після `settings.js`:

   ```html
   <script src="neptun/settings.js"></script>
   ```

4. `app/main.js` — після рядка `const sysmon = require('./sysmon');`:

   ```js
   require('./neptun/main'); // NEPTUN targets layer: opens its links in the browser
   ```

5. `app/preload.js` — останнім пунктом у `contextBridge.exposeInMainWorld('bridge', { … })`:

   ```js
   // NEPTUN targets layer (app/neptun): its own IPC channels, all prefixed "neptun:".
   neptun: {
     send: (channel, data) => ipcRenderer.send('neptun:' + channel, data),
     on: (channel, cb) => ipcRenderer.on('neptun:' + channel, (_e, data) => cb(data)),
   },
   ```

   Без цього кроку все працює, крім плашки.

`app/assets/map.json` міняти не обов’язково: параметри проєкції поточної карти вшиті в `widget.js`.

## Налаштування

Розділи «Карта» і «Цілі на карті» у вікні налаштувань. Значення — у `%APPDATA%\trevoga-map\settings.json`:

```json
"neptun": { "markers": true, "panel": true, "hideFpv": false, "alert": true, "alertKm": 20, "alertSound": false, "cardSide": "left", "basemap": "none", "booms": true, "ticker": true, "style": "bright" }
```

| Ключ | Що означає |
| --- | --- |
| `markers` | Показувати цілі. Вимкнено — з’єднання закривається, усе інше ховається |
| `panel` | Плитки з кількістю цілей під картою |
| `hideFpv` | Приховати FPV-дрони скрізь |
| `alert` | Плашка, коли нова ціль входить у радіус |
| `alertSound` | Короткий подвійний сигнал разом із плашкою; гучність — з розділу «Сповіщення» |
| `cardSide` | Вікно під картою: `left` або `right` (на широкому віджеті) |
| `basemap` | Підкладка: `none`, `map` (дороги), `sat` (супутник), `hybrid` (супутник і дороги), `dark` (темний супутник); працює й з вимкненими цілями |
| `booms` | Вибухи з постів каналів на карті |
| `ticker` | Стрічка подій під картою |
| `homeRing` | Тонке пунктирне коло радіуса навколо вашої точки (за замовчуванням є) |
| `alertKm`, `alertKmMissile` | Радіус сповіщень для дронів і для ракет, КАБ, авіації: будь-яке ціле число км 1–500 (у списку — підказки); навколо вашої точки — два кола |
| `fastKm` | Швидке читання каналів (8–10 с), коли ціль ближче за свій радіус плюс стільки км (0 — вимкнено; типово 50) |
| `tgTargets` | Показувати цілі з ваших каналів, яких ще немає в NEPTUN (типово так) |
| `channels` | Ваші публічні канали Telegram (`["shpk_krop", "krop_vanek"]`): `main.js` читає `t.me/s/<канал>` раз на 45 с (номер поста й пост, на який він відповідає), пости йдуть у `intel.js` і `routes.js`; «реактивний» у вашому каналі — достатньо для реактивного шахеда |
| `home` | Ваша точка `{ lat, lon }`: відстань, радіус сповіщень і «Біля вас» рахуються від неї замість меж районів; ставиться кнопкою ⌖ на карті або координатами в налаштуваннях |
| `style` | Вигляд панелей під картою: `bright` (яскравий) або `calm` (акуратний: один шрифт, без підсвітки й градієнтів, колір — лише в статусах) |
