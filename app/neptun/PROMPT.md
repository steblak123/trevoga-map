# Слой целей для «Карты тревог»: что сделано, как и откуда

Этот файл — полное описание папки `app/neptun` и связанных с ней правок. Его можно читать как документацию
или целиком отдать новой сессии Claude как промпт (готовый текст — в конце). План развития всего проекта —
в [`docs/PLAN.md`](../../docs/PLAN.md).

## 1. Что это за проект

«Карта тривог» (`steblak123/trevoga-map`) — прозрачный виджет Electron для рабочего стола Windows: карта Украины
с районами, официальные воздушные тревоги, «мои районы» с плашкой поверх окон, панель нагрузки ПК под картой.

| Что | Откуда | Где в коде |
| --- | --- | --- |
| Тревоги по областям и районам | API alerts.in.ua, нужен токен | `app/main.js` (опрос), `app/widget.js` (раскраска) |
| Границы областей и районов | OCHA / HDX COD-AB Ukraine, CC BY-IGO | `build/make-map.js` → `app/assets/map.json` |
| **Цели: дроны, ракеты, КАБ, авиация** | **открытый API NEPTUN (neptun.in.ua), без токена** | **`app/neptun/`** |
| Нагрузка ПК | Windows API (PDH, DXGI, iphlpapi) | `app/sysmon.js`, `app/native.js` |

В интерфейсе названия источников не пишутся: так решил владелец. Источники указаны только в документации.

## 2. Что умеет слой целей

**На карте — только графика, без текста:**

1. **Отметки целей.**
   - Иконка по виду: шахед, реактивный шахед, FPV, разведчик, крылатая ракета, баллистика, КАБ, МиГ-31К,
     неизвестная.
   - Указатель курса снаружи кружка, «×2» для группы из сообщения.
   - Отметка движется по курсу и скорости от последнего упоминания, с пределами по времени и км для каждого вида
     (таблица в `types.js`).
2. **Реактивные шахеды.** У NEPTUN тип один (`uav`), реактивность — только в названии («Реактивний шахед»).
   `kindOf()` выделяет их в отдельный вид `jet`: своя иконка (стреловидное крыло, сопло), цвет, плитка,
   пределы прогноза как у быстрой цели. FPV распознаётся и по типу, и по названию.
3. **Траектории.**
   - Откуда: линия по точкам `trail`, затем точка сообщения и текущая расчётная позиция, кружок в начале.
   - Куда: полупрозрачный сектор вперёд по курсу, примерно на 10 минут полёта, но не короче, чем выходит за кружок.
     Ширина ±12° при известной скорости, ±22° при оценочном курсе.
   - У выбранной цели всё ярче, плюс пунктирная линия курса на 60 км и круг погрешности.
4. **Дроны без курса** (шахеды и разведчики) не рисуются, если они не ближе 50 км к вашим районам. Они есть
   в плитках («N без курсу») и открываются оттуда. Так делает и карта NEPTUN: «Дрони без курсу на карті не малюємо,
   хіба що вони поруч із Домом».
5. **«×N»** — одна отметка для целей, которые на экране ближе 15 px друг к другу. Клик открывает список в окошке.
6. **Цели за краем видимой карты** прижаты к краю: пунктирный кружок, белая стрелка в сторону цели.
7. **Пунктирный контур области** — для сообщений, где названа только область (`areaOnly`).
8. **Над морем.** Если у цели нет населённого пункта, а точка вне суши Украины, подпись будет
   «над Чорним морем · у бік Одеської області» (Азовское море — так же).

**Под картой, рядом с плитками нагрузки ПК — в одной сетке и того же вида:**

9. **Окошко** — две плитки в высоту, слева или справа (настройка `cardSide`); на узком виджете на всю ширину.
   - По умолчанию: «Біля ваших районів · до 20 км» и время данных, затем все цели в радиусе, и новые, и давние:
     «Шахед ×2 — ≈ 12 км · Бучанський р-н · наближається · поруч 14 хв». Если рядом никого — «Поруч нікого»
     и самая близкая цель.
   - Клик по цели на карте или по строке показывает здесь её курс, скорость, время упоминания, источники,
     достоверность, точность, расстояние и пояснение. ✕ возвращает список.
   - Клик по «×N» показывает здесь список группы.
10. **Плитки с мини-графиком за 30 минут** (отсчёт раз в 30 с), как у ЦП и памяти: «Усього цілей · N без курсу»,
    по видам («Реактивні», «БпЛА», «FPV», «Ракети»…; вид, который был за 30 минут, остаётся с 0) и «Біля вас (20 км)».
    Последняя оранжевая, если кто-то рядом. Клик по плитке — эти цели по очереди, наведение — их список.

**Ещё:**

11. **Зум** (`zoom.js`).
    - Кнопки справа вверху под шестерёнкой: «+», «−», «◎» (мои районы), «⤢» (вся карта). Колесо мыши над картой.
    - Перетаскивание наближенной карты двигает карту; в обычном масштабе перетаскивание, как раньше, двигает виджет.
    - Отметки и подписи областей сохраняют размер.
12. **Плашка «Ціль біля ваших районів»** справа вверху экрана — только когда новая цель входит в радиус
    5/10/20/50 км.
    - 2 секунды, полупрозрачная, сквозь неё можно кликать.
    - Звук по умолчанию выключен.
    - Выход из радиуса — дальше 1,3 радиуса. Смена настроек плашку не вызывает.
    - Наблюдения (`advisory`) и старые треки (`stale`) не оповещают.
13. **Скрыть FPV** — с карты, из окошка, плиток и плашек.
14. **Плашки тревоги и отбоя** (`app/overlay.*`) — тоже на 2 секунды, полупрозрачные, без ✕, сквозь них можно кликать.

## 3. Откуда данные: API NEPTUN

Документация: <https://neptun.in.ua/developers>, условия: <https://neptun.in.ua/api-terms>. Ключ не нужен,
CORS открыт, только чтение.

- **WebSocket** `wss://neptun.in.ua/api/v1/stream` — основной канал. Кадры `{ type, ts, data }`:
  `snapshot` (`{ threats }`), `upsert` (цель), `remove` (`{ id }`), `heartbeat` (около 15 с),
  `alerts` (не используется).
- **REST** `GET https://neptun.in.ua/api/v1/threats` — тот же снимок, только как резерв при обрыве,
  не чаще раза в 15 с.

Поля цели, которые использует слой:

- `id`, `type`, `title`;
- `lat`, `lon`, `heading`, `velocity { bearingDeg, speedKmh }`, `confirmedAt`;
- `locality`, `district`, `region`;
- `destination` — названо только, куда летит;
- `presumptiveCourse` — курс оценочный;
- `count`;
- `sourceCount`, `confidenceLevel`, `displayConfidence`, `uncertaintyKm`, `positionQuality`;
- `status` (`active`, `stale`, `resolved`);
- `advisory`, `areaOnly`;
- `trail` — прошлые точки `{ lat, lon, t }`;
- `explanationShort`, `updatedAt`.

Типы API: `uav`, `fpv`, `recon`, `missile`, `ballistic`, `kab`, `mig31k`, `unknown`. Вид `jet` выводится из
названия.

## 4. Как это устроено

### Координаты → карта

`map.json` построен в проекции Ламберта (`+proj=lcc +lat_1=45 +lat_2=51 +lat_0=48.5 +lon_0=31.5 +datum=WGS84`)
и вписан в ширину 1000. `build/make-map.js` пишет в `map.json` поле `proj: { lat1, lat2, lat0, lon0, x0, y1, k }`,
переход в координаты карты: `X = (x − x0)·k`, `Y = (y1 − y)·k`.

`geo.js` повторяет ту же проекцию (формулы Снайдера), сверено с mapshaper до 1 мм. Без `proj` в `map.json` берутся
те же значения из `widget.js`. Расстояние в км = единицы карты / (k·1000), погрешность около 1 %.
Зум меняет только `viewBox` карты. Размер отметок пересчитывается из `getScreenCTM()`, поэтому на экране
он постоянный.

### Поток данных

```
NEPTUN WebSocket ──► client.js (окно виджета) ──► widget.js: отметки, траектории, окошко, плитки
                         │ обрыв → REST раз в 15 с          │ раз в 2 с: прогноз, расстояния, кто вошёл в радиус
                         │ тишина 50 с → переподключение    │ раз в 30 с: точка истории для плиток
                                                          ▼  (только новые цели рядом)
                     window.bridge.neptun.send('alert', …)  (preload.js)
                                                          ▼
                     neptun/main.js ──► окно alert.html справа вверху, 2 с, сквозь него можно кликать
                         ◄── 'alert-done'
```

- **Клиент** работает в окне виджета: в главном процессе Electron 33 (Node 20) нет встроенного WebSocket.
- **Каналы IPC** (`neptun:*`): `alert` (виджет или «Перевірити» в настройках → главный процесс), `alert-size`,
  `alert-done`.
- **Кто рядом.** Расстояние считается до ближайшей границы выбранных районов (полигоны из `map.json`; внутри — 0).
  Вход ≤ радиуса, выход — дальше 1,3 радиуса. Для каждой цели хранится время входа («поруч N хв»).
  «Наближається» значит, что точка в 3 км впереди по курсу ближе.
- **Над морем.** Точка вне всех полигонов районов попадает в рамку Чёрного или Азовского моря.
- **Клики.** Виджет пропускает мышь сквозь пустые места. Над отметками, окошком, плитками и кнопками (класс `ui`)
  мышь ловится. События `mousedown` и `dblclick` на элементах слоя останавливаются, поэтому клик не двигает окно.
  При перетаскивании наближенной карты у `#map` временно появляется класс `ui`.
- **Высота окна.** Если окошко и плитки сжимают карту, слой один раз просит главный процесс увеличить окно
  (`bridge.fitHeight`) — как это делает панель ПК.

## 6. Настройки

Раздел «Цілі на карті». Значения хранятся в `%APPDATA%\trevoga-map\settings.json`:

```json
"neptun": { "markers": true, "panel": true, "hideFpv": false, "alert": true, "alertKm": 20, "alertSound": false, "cardSide": "left" }
```

- `markers` — показывать цели; выключено — соединение закрывается и всё прячется.
- `panel` — плитки с количеством под картой; окошко есть всегда, пока цели включены.
- `hideFpv` — скрыть FPV.
- `alert` и `alertKm` (5/10/20/50) — плашка и радиус; радиус действует и для окошка, и для плиток.
- `alertSound` — звук, по умолчанию выключен.
- `cardSide` — окошко слева (`left`) или справа (`right`).

## 7. Как проверялось

- Настоящий `widget.html` открывался в Chromium (Playwright) с подменой `window.bridge`:
  - на живых данных NEPTUN;
  - на тестовом наборе: все виды, реактивный, FPV с типом `uav`, дроны без курса далеко и рядом, дроны в море
    без курса и с курсом, треки, группа, цели за краем, «только область».
- Проверено:
  - какие отметки рисуются (без курса далеко — нет, рядом — да);
  - траектории и секторы;
  - окошко: список, детали, группа, ✕; плитки и их подсказки, клик по плитке;
  - скрытие FPV везде;
  - окошко справа и слева;
  - зум: кнопки, колесо, «мои районы», перетаскивание не двигает окно, в 1× окно двигается как раньше;
    отметки того же размера;
  - плашка только для новых целей, смена радиуса без плашки;
  - переподключение и REST-резерв;
  - `overlay.html` и `alert.html` исчезают через 2 с;
  - в тексте виджета нет названий источников.
- `neptun/main.js` проверен с подменённым модулем `electron`.
- **Не проверено в реальном Electron на Windows**: такой среды не было.

## 9. Ограничения

- Позиции — из сообщений в Telegram-каналах через NEPTUN: приблизительные, могут опаздывать на минуты.
- **Атрибуция.** Условия NEPTUN и alerts.in.ua требуют видимой ссылки на источник. По решению владельца подписи
  убраны; вернуть можно по истории git (строка `#credit` в `app/widget.html`).
- В режиме «Під ярликами» отметки видны, но клики, наведение и зум не работают.
- История плиток хранится в памяти: после перезапуска виджета графики начинаются заново.
- Дальнейшие идеи и что из них реально — в [`docs/PLAN.md`](../../docs/PLAN.md).
